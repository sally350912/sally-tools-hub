No.13

短影音腳本 Prompt 產生器

文案內容已上線

填平台、主題、受眾、長度與 CTA，產出一段完整 prompt——含前 3 秒鉤子、逐段口白＋字幕＋B-roll、結尾 CTA 與 hashtag。複製貼進 ChatGPT／Claude 就生腳本。

sally-atelier / video-script
HOW TO USE — 三步驟
i.

選平台與長度

Reels／TikTok／Shorts × 15／30／60 秒，工具會調整節奏與結構。

ii.

填主題與 CTA

說清楚要講什麼、給誰看、最後想讓觀眾做什麼。

iii.

複製貼進 AI

產出的 prompt 貼進 ChatGPT／Claude，先挑一個鉤子，再請它依結構展開。

使用前請知道 NOTES

  • 前 3 秒鉤子最關鍵——AI 給你三個選項，挑最戳你受眾的那個。
  • 口白記得自己唸一次抓時間，太長就砍句子，一句一個重點。
  • 這工具不呼叫 AI、不花錢、不收資料，只幫你把 prompt 寫好。
